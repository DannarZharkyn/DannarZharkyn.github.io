# Original thesis figures

Extracted without image edits from Dannar Zharkyn’s bachelor’s thesis,
“Робот-көмекшіні басқару жүйесін әзірлеу” (2023).

- web-interface.jpeg: Figure 31, administrator web interface (word/media/image31.jpeg).
- android-compass.jpeg: Figure 36, Android compass interface (image36.jpeg).
- delivery-workflow.jpeg: Figure 2, intended delivery workflow in Kazakh (image2.jpeg).
- arduino-mega.jpeg: Figure 18, Arduino Mega component (image18.jpeg).
- esp8266.jpeg: Figure 22, NodeMCU Wi-Fi module (image22.jpeg).
- ultrasonic.jpeg: Figure 21, HC-SR04 sensor (image21.jpeg).

These component photographs do not show an assembled robot. Figures 3–6 depict
commercial examples and are not used. Configuration screenshots and the thesis
source document are not published.

Content basis: sections 2.1–2.3, 3.1–3.2, conclusion, and code appendix.
The testing chapter demonstrates Firebase writes from the web and Android apps.
The conclusion reports a successful test delivery; no quantitative performance
or repeatability results are supplied. The portfolio distinguishes these levels
of evidence.
