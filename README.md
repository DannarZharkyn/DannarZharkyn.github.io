## Optional visitor counter

GoatCounter is connected through `src/data/analytics.ts`. The owner dashboard is https://dannar.goatcounter.com. Set the endpoint to an empty string to disable collection. Keep the dashboard private. In GoatCounter collection settings, disable browsers, systems, locations, languages, screen sizes, and individual pageviews for minimal aggregate counting.

The shared layout loads the script only in production when configured. All portfolio pages report the same `/` path, with an empty title and referrer and no click tracking. There is no visible counter or popup. GoatCounter uses no visitor cookies; its dashboard account uses login cookies. Counts are estimates, and blocked scripts cannot be counted.
